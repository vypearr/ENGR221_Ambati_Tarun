a. Recursive memory usage: 42.73046875 MB

Recursive time taken: 4.96858 s
Non-recursive time taken: 4.81862 s

b. These results make sense because both methods draw the same Koch snowflake, so their time taken is close. The recursive method took 4.96858 seconds, while the non-recursive stack method took 4.81862 seconds, so the stack method was slightly faster in this run. Since both methods still have to draw the same number of turtle line segments, the runtime difference is not huge.
The bigger difference is in memory usage. The recursive method used 42.73046875 MB, while the non-recursive method used 30.8125 MB. This makes sense because recursion adds many function calls onto Python’s call stack. Each recursive call stores information like the current length, depth, and where the program should continue after that call finishes. The non-recursive method uses a list as a stack to store commands instead, which avoids creating all those nested function calls. Because of that, the non-recursive stack method used less memory.
