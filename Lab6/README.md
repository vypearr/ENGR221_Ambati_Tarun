Files

- tree_node.py: Defines the TreeNode class and implements tree methods such as add_child(), remove_child(), is_leaf(), depth(), height(), and find().
- engr_faculty.py: Reads faculty data from faculty_list.xlsx, creates Professor objects, stores them in a dictionary, builds the School of Engineering tree, and starts the visualizer.
- faculty_visualizer.py: Uses pygame to draw the faculty tree and lets the user search for a professor by last name.
- professor.py: Defines the Professor class and constants for professor rank and engineering program.
- preferences.py: Stores constants used throughout the program, such as colors, screen size, fonts, and file paths.
- faculty_list.xlsx: Spreadsheet containing faculty information.
- headshots: Folder containing professor headshot images.
