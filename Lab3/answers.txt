PART 2:

a. Selection sort works by selecting the smallest value from the unsorted part of the list and swapping it into the next correct position. It is called selection sort because each pass selects the next smallest item.

b. Selection sort is O(n^2). You can tell from the code because it has a loop inside another loop. For each outer loop index i, the inner loop searches through the remaining unsorted items.

c. Selection sort is O(1) extra space. It sorts the original list in place and only uses a few extra variables like i, j, and min_idx instead of creating a new list.


PART 3: 

a. Insertion sort builds a sorted section on the left side of the list. It takes the next item and inserts it into the correct spot by moving it left until it is in order. It is called insertion sort because each new item is inserted into the sorted portion.

b. Insertion sort is O(n^2) in the worst case. The pseudocode has a for loop, and inside it there is a while loop that may move the current item across much of the list.

c. Insertion sort is O(1) extra space because it sorts the same list in place and only uses a few variables such as i and j.


PART 4: 

a. Bubble sort compares neighboring items and swaps them if they are out of order. Larger values slowly move, or bubble, toward the end of the list after each pass.

b. Bubble sort is O(n^2). You can tell because the pseudocode uses a nested loop: the outer loop makes passes through the list and the inner loop compares adjacent values.

c. Bubble sort is O(1) extra space because it sorts in place and only uses loop variables and temporary swapping, not a new list.

The -i works because after each full pass of bubble sort, the largest remaining item has already moved to the end of the list. That means the last i items are already sorted and do not need to be checked again. Skipping them gives the same sorted result with fewer comparisons.
