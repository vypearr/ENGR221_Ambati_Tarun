Files

- controller.py: Runs the game loop, handles keyboard input, updates the game, and draws the screen.
- display.py: Draws the board, score, player, body, food, and game-over screen.
- cell.py: Defines the Cell class and the possible cell types.
- preferences.py: Stores constants for board size, colors, images, and timing.
- game_data.py: Stores and updates the game state. This file was modified for player movement, food collection, and AI pathfinding.
- search_structure.py: Defines custom Queue and Stack classes. This file was modified for BFS and DFS.

Modified Files

- game_data.py
- search_structure.py


How to Run

- python controller.py

Movement: Use Arrow Keys, For AI mode press 'a'
