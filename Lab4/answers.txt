Part 3
a. When i ran AI mode with DFS it searched for ducks horizontally going row by row after getting the first duck. and then it got stuck in a loop of
2 rows and never got out. This happens because DFS uses a stack, so it follows one path as far as possible before checking other paths. 
DFS does not search evenly outward from the player. Because of this, it can choose a path that is not the shortest or smartest path to the duck.
In the game, this can make the player move in a repetitive pattern or get stuck because DFS keeps prioritizing the most recently added cells instead of checking all nearby options first
b. BFS will find a shorter path to the food. BFS uses a queue, so it checks cells layer by layer based on distance from the player. 
That means the first food it finds is reached using the fewest number of moves.
